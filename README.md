# Prasanna Allu — profile site

`index.html` is a complete, self-contained page. Copy this folder's contents
into a GitHub repository and turn on Pages; there is nothing to build or
install on the GitHub side.

```
index.html    the page
.nojekyll     tells Pages to serve the directory as-is
```

## Putting it up

**A user site** — served at `https://<username>.github.io/`:

```bash
git init && git add . && git commit -m "profile site"
git remote add origin git@github.com:<username>/<username>.github.io.git
git push -u origin main
```

Pages turns itself on for a repository named `<username>.github.io`.

**A project site** — served at `https://<username>.github.io/<repo>/`: push to
any repository, then **Settings → Pages → Build and deployment → Deploy from a
branch**, and pick `main` / `/ (root)`.

Either way the first build takes a minute or two.

## After it is live

Set `meta.siteUrl` in `data/profile.json` to the published address and rebuild.
That fills in the canonical link and the Open Graph tags, so the link previews
properly when it is pasted into LinkedIn, Slack or a message.

## What is in the file

One HTML file, and nothing fetched at runtime except Google Fonts. Every
drawing is inline SVG, so there are no image requests, no build step and no
dependency that can rot.

The page follows the reader's system light/dark setting and carries its own
theme toggle, top right; the choice is remembered in that browser.

## Do not edit this file

It is generated. Facts live in `data/profile.json` and the layout lives in
`templates/quest_log.py`, one directory up. Change those and run:

```bash
python3 build.py
```

Editing `index.html` directly means the next build silently discards the change.
